节点风格
连线透明度 .32
连线取两端节点色做渐变，一眼能读出「从哪来、去哪」。流向终止的连线额外降透明度，视觉上表现为「这条路走到这儿断了」。 流量过小、色块高度不足 16px 的节点会隐藏文字标签，避免串到相邻节点上，hover 可看明细。

使用规则
项规则
页面色稳定性同一 pageId 在热力图、桑基图、页面清单里必须同色。已登记页面走 PAGE_COLOR_MAP，未登记页面按 pageId 做 hash 取模，保证多次渲染不变色。
连线颜色lineStyle.color:'gradient'，透明度 0.28–0.36。超过 0.4 时多条流带交叉处会出现脏色块。
中性色保留三个中性色只给「其他 / 更多 / 终止」，不参与业务色轮转。业务页面再多也从 20 色里取，避免与语义节点混淆。
色相语义三档明度接近（都是低饱和浅色）：其他=浅蓝灰、更多=冷灰绿、终止=极浅蓝灰。整体沉入背景，不与业务色抢注意力。
非颜色区分三个中性色明度相近，颜色不承担主要区分职责：「更多」加虚线描边和 › 后缀，「终止」入边透明度降到正常值的 55%，靠形态与位置传递结构语义。
块内文字按节点色相对亮度自动选深色 #17181a 或白色，保证对比度不低于 4.5:1，不用手工维护文字色表。
薄节点标签按 value / 最大列总量 × 可用高度 估算色块高度，低于 16px 隐藏标签、16–26px 降到 10px 字号。硬放会串行重叠。
感知明度齐平不要直接照搬 Material 同一级色。200 级里黄系相对亮度高达 0.89，蓝紫系只有 0.39，同级并不等于同明度。黄 / 黄绿 / 琥珀 / 浅绿已按同色相压到 ~0.60，保证白底上描边和填充都能看清。
相近色回避全色板明度拉平后，紫系（紫 / 深紫 / 蓝紫）、暖黄系（黄 / 琥珀 / 橙）、绿系（绿 / 浅绿 / 黄绿）三组内部色差较小，排布时避免让同组色在相邻层级直接相接。
