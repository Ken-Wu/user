# 热力图实现规则

## 1. 文档范围与结论

本文基于当前工作区内的 5 个页面实现整理，适用于“页面分析”中的模块级热力图。所有源文件中的业务数据均为演示数据；接入真实数据时，应保留其字段口径、坐标映射和联动关系，不应直接把演示数值当作生产口径。

现行实现以 `app/pageanalysis_heatmap_v2_scheme10.html` 为准，以下简称“方案 10”。方案 10 不绘制点击散点，也不使用连续 Canvas 热场作为最终可见图层；它将每个模块映射为一个独立的 DOM 自适应椭圆色块，用 UV 指标分档着色。文件中仍保留旧 Canvas 绘制函数和调参代码作为历史实现，但同名 `buildHeat` 在后文被方案 10 的版本覆盖，且 `.heat-cv` 被设置为不显示。

## 2. 版本定位与适用场景

| 文件 | 定位 | 热力呈现 | 适用场景 |
| --- | --- | --- | --- |
| `app/pageanalysis_heatmap_v2_scheme10.html` | 现行方案 | DOM 自适应椭圆、四色离散分档 | 模块级埋点只有聚合指标，需清晰表达模块整体热度时使用 |
| `app/pageanalysis_heatmap_v2.html` | 历史连续热场方案 | Canvas 有机连续热场 | 需要比较连续颜色、热核和边缘衰减效果时参考 |
| `app/heatmap_demo.html` | 热力图实验台 | DOM 色块、多套配色和方案 10 控制项 | 评审色彩、透明度、模糊及椭圆尺寸时使用，不作为页面分析主入口 |
| `app/pageanalysis_heatmap_v2_品类列表窄版.html` | 历史坐标变体 | Canvas 有机连续热场 | 只需突出品类列表右侧勾选列，而非整块列表时参考 |
| `app/pageanalysis_heatmap_v2_旧热力图撒点版_20260918.html` | 历史撒点方案 | Canvas 多点密度场 | 研究点云形态时参考；模块级数据没有真实点击坐标时不应作为现行呈现 |

## 3. 目标与页面构成

页面用于把“询价页”截图上的模块区域与模块分析数据表联动，帮助查看模块曝光、点击和使用情况。页面由以下区域构成：

1. 固定顶栏与页面分析筛选区。
2. 页面数据卡，包括页面 KPI、流量来源和流量去向。
3. 左侧页面热力图卡：手机壳、页面截图、截图遮罩、热区和指标标签。
4. 右侧模块数据卡：模块数据和页面行为数据两个页签。
5. 模块操作步骤卡：由 ECharts 渲染的桑基图，用于查看选中模块后的下游步骤。
6. 品类列表与策略明细弹窗，以及模块埋点 ID、曝光类型等说明浮层。

热力图只表达“模块级热度”，不能被解释为真实点击坐标分布。特别是旧撒点版中的点位由确定性伪随机数生成，只用于视觉试验，不是埋点回传坐标。

## 4. 方案 10 的现行实现规则

### 4.1 渲染职责

方案 10 使用截图作为底图，使用 DOM 区块承载交互、描边、标签和离散热色块：

- `.ph-shot` 负责页面截图，宽度自适应，高度由图片比例决定。
- `.shot-mask` 提供 `#4294B5`、透明度 `0.06` 的冷色遮罩，保证底图与热区可辨。
- `.zone` 是一个模块的可点击区域，拥有 `data-mod` 作为与模块表联动的唯一名称键。
- `.zone-heat-clip` 负责裁切热色块；`.zone-fill` 负责绘制居中的椭圆色块。
- `.zone::before` 绘制模块的白色描边；标签 `.hot` 位于区块上沿。
- `.heat-cv` 在方案 10 中为 `display:none`，不承担现行热力图呈现。
- ECharts 不用于热力图本身，仅用于“模块操作步骤”的桑基图。

现行热区在截图加载完成、窗口尺寸变化及截图容器尺寸变化时重算。任何新页面若使用相同模式，必须在图片实际尺寸可用后执行热区计算。

```javascript
const draw = () => {
  syncZoneLabels();
  buildHeat();
  fitHots();
};

if (shot.complete) draw();
else shot.addEventListener('load', draw);
window.addEventListener('resize', draw);
new ResizeObserver(() => {
  buildHeat();
  fitHots();
}).observe(heatWrap);
```

### 4.2 模块数据模型与字段语义

现行模块数组以 `name` 连接热区和表格，以 `eventId` 支持悬浮复制埋点 ID。建议真实接口至少映射为同等语义字段。

| 字段 | 现行含义 | 用途 |
| --- | --- | --- |
| `name` | 模块名称 | 必须与 `.zone[data-mod]` 完全一致，用于双向联动 |
| `expo` | 周期内模块曝光 PV | 计算日均曝光、PV 点击率、曝光率 |
| `ctr` | PV 点击率 | 计算点击 PV，即 `expo × ctr` |
| `ctrUv` | UV 点击率覆盖值 | 可选；存在时优先作为 UV 点击率，例如品类列表组 |
| `eventId` | 模块埋点 ID | 模块名悬浮提示和复制 |
| `action` | 演示中的操作说明 | 当前仅作数据说明，不参与热区计算 |

现行页面还定义模块曝光类型：`page` 表示随页面曝光、`self` 表示模块进入可视区曝光、`parent` 表示采用父模块曝光、`none` 表示未配置曝光。`parent` 类型携带 `parentId`，说明浮层可复制该父模块 ID。

UV 与 PV 计算集中在函数中，避免表格与热区分别计算后不一致。当前演示的 UV 去重系数为 `0.78`，重复点击系数来自 `MOD_REPEAT`；真实接入时应由数据服务直接提供 UV 和 PV，或将这些演示假设替换为明确的数据口径。

```javascript
function modClick(m) {
  return Math.round(m.expo * m.ctr);
}

function modExpoUv(m) {
  return Math.round(m.expo * 0.78);
}

function modCtrUv(m) {
  if (m.ctrUv != null) return m.ctrUv;
  const expoUv = modExpoUv(m);
  return expoUv > 0 ? modClickUv(m) / expoUv : 0;
}

function modUsageUv(m) {
  return (modClickUv(m) / getDays()) / pageDailyUv;
}
```

现行规则中的指标含义如下：

| 指标 | 现行计算口径 |
| --- | --- |
| 日均曝光 | 周期曝光量除以筛选日期包含的天数 |
| 日均点击 | 周期点击量除以筛选日期包含的天数 |
| 点击率 | 模块点击 UV ÷ 模块曝光 UV，表格同时展示 UV 和 PV |
| 使用率 | 模块日均点击 UV ÷ 页面 UV |
| 曝光率 | 模块曝光 ÷ 页面可达量，页面可达量以最高曝光模块除以 `0.995` 近似 |

### 4.3 坐标与模块映射

热区坐标使用相对于截图容器的百分比，`left`、`top`、`width`、`height` 均必须以同一张截图为基准。百分比坐标使 300px 宽的手机预览能随截图等比缩放，而无需保存固定像素坐标。

```javascript
const zone = {
  mod: '发单按钮',
  left: 55,
  top: 90,
  width: 44,
  height: 7
};

zoneElement.style.left = zone.left + '%';
zoneElement.style.top = zone.top + '%';
zoneElement.style.width = zone.width + '%';
zoneElement.style.height = zone.height + '%';
```

方案 10 不从 `--heat` 变量计算颜色，而是读取同步后的标签百分比，按当前指标的值决定分档。切换“点击率”与“使用率”时，必须先刷新标签，再重建热区。当前方案默认展示点击率，工具栏可切换为使用率；数据标签固定显示，没有“隐藏数据”开关。

模块标签必须避免超出手机边界并尽量避免互相遮挡。`fitHots` 会按从上到下、从左到右的顺序摆放，优先原位，再尝试向下或向上错开；无可用位置时宁可保留重叠，也不让标签移到无关模块。

### 4.4 自适应椭圆几何规则

方案 10 的热色块是居中椭圆，而非铺满整个模块，也不是全局网格插值。椭圆宽高由模块实时尺寸扣除内边距计算，保证长条模块保持长条形、窄模块保持窄形。

| 规则 | 当前值 | 说明 |
| --- | --- | --- |
| 最小模块面积 | 小于 `2500px²` | 使用小模块内边距 |
| 中模块内边距 | `16px` | 默认内边距 |
| 大模块面积 | 大于等于 `12000px²` | 使用大模块内边距 |
| 大模块内边距 | `28px` | 为大区块保留更明显边距 |
| 小模块内边距 | `8px` | 防止椭圆被压缩得不可见 |
| 最小椭圆宽高 | 不超过模块尺寸的 `12px` | 确保极小模块仍可显示热色 |
| 图层模糊强度 | `39px` | 还会受面积档位和几何边距约束 |
| 模糊上限 | 小 `8px`、中 `16px`、大 `36px` | 防止小模块模糊溢出 |

```javascript
const heatWidth = Math.max(minimumWidth, moduleWidth - insetX * 2);
const heatHeight = Math.max(minimumHeight, moduleHeight - insetY * 2);
const blurRadius = Math.min(39, blurCap, geometryCap);

zone.style.setProperty('--scheme10-heat-width', heatWidth + 'px');
zone.style.setProperty('--scheme10-heat-height', heatHeight + 'px');
zone.style.setProperty('--scheme10-blur-radius', blurRadius + 'px');
```

只对 `.zone-fill` 施加图层模糊。标签、白色描边和交互轮廓必须保持清晰，不应跟随模糊。现行方案使用 `filter: blur()`，不使用 Canvas 的热核模糊，也不启用背景模糊。

### 4.5 颜色与强度分级

方案 10 使用四个硬边离散档位，不做色相插值。阈值由标签中的百分数判断，边界为 `10%`、`30%`、`55%`：

| 点击率或使用率 | 色值 | 当前透明度 |
| --- | --- | --- |
| 小于 `10%` | `rgba(0,178,255,.32)` | `0.32` |
| `10%` 至小于 `30%` | `rgba(115,255,218,.32)` | `0.32` |
| `30%` 至小于 `55%` | `rgba(255,229,128,.32)` | `0.32` |
| 大于等于 `55%` | `rgba(255,128,160,.32)` | `0.32` |

```javascript
function scheme10Color(rate) {
  const thresholds = [10, 30, 55];
  const colors = [
    'rgba(0,178,255,.32)',
    'rgba(115,255,218,.32)',
    'rgba(255,229,128,.32)',
    'rgba(255,128,160,.32)'
  ];
  let index = 0;
  while (index < thresholds.length && rate >= thresholds[index]) index++;
  return colors[index];
}
```

颜色数量、阈值数量和表意必须同步调整。若业务需要增加等级，应同时更新配色数组、阈值、图例、验收用例和热区说明；不要在方案 10 中改为连续渐变，否则会改变现行离散分档的表达方式。

### 4.6 筛选、表格、悬浮和点击交互

筛选区包含行为分析、页面、日期范围、平台、流量入口、城市群、同跨城、里程段、实时或预约、新老客。日期变化与页面变化会执行 `refreshAll`；当前演示会刷新流量表、模块表和桑基图，其他筛选项为静态控件。接入真实查询时，所有筛选项应作为同一份查询参数传给后端，再统一刷新数据与热区。

模块表可按模块名、日均曝光、曝光率、日均点击、点击率、使用率排序。方案 10 的曝光或曝光率排序会把“有曝光数据”的行置于“无曝光数据”的行之前；无曝光模块显示 `-`。

| 入口 | 当前行为 |
| --- | --- |
| 点击热区 | 选中对应热区和模块表行，并只滚动模块表内部容器，不切换桑基图起始模块 |
| 点击模块表行 | 选中热区和表格行，并将该模块作为桑基图起始模块 |
| 悬浮热区 | 对应模块表行显示 hover 状态 |
| 点击页面空白处 | 清除热区和模块表的选中态 |
| 点击“隐藏热力图” | 隐藏椭圆填色和边框，选中及 hover 轮廓仍可用 |
| 点击指标切换 | 在点击率与使用率间切换，重新生成标签、热区和标签布局 |
| 悬浮模块名 | 显示并可复制该模块的 `eventId` |
| 悬浮曝光说明 | 显示曝光类型；父模块曝光可复制父模块 ID |

联动需要共享相同的模块名键。点击热区时应显式传入 `false`，避免仅查看热区时改变桑基图上下文。

```javascript
function selectModule(name, syncSankey = true) {
  document.querySelectorAll('#modTable tr').forEach((row) => {
    row.classList.toggle('sel', row.dataset.name === name);
  });
  document.querySelectorAll('.phone .zone').forEach((zone) => {
    zone.classList.toggle('sel', zone.dataset.mod === name);
  });
  scrollWithin(
    document.querySelector(`#modTable tr[data-name="${name}"]`),
    document.querySelector('#mdPane0 .md-scroll')
  );
  if (syncSankey) showModSankey(name);
}
```

### 4.7 详情与图表

模块表中的“品类列表-组”可打开品类点击明细，券包和优惠 banner 的策略数据可打开策略明细。弹窗使用遮罩层，并把表格置于内部滚动容器中。

ECharts 的使用边界是模块操作步骤桑基图：按起始模块、展示步数和每步 Top N 生成节点和连线，并在 tooltip 中展示操作量、点击 PV、点击 UV、终止量和终止率。热力图实现不依赖 ECharts。

## 5. 布局、响应式与样式约束

### 5.1 页面与双栏布局

- 顶栏为固定定位，高度 `64px`，正文以 `padding-top: 64px` 留出空间。
- 筛选区使用最小宽度 `213px` 的自动填充网格；时间范围跨两列。
- 热力图与模块数据在宽屏使用双栏布局，左卡固定基础宽度 `461px`，中间间隔 `20px`。
- 右侧模块卡高度应跟随左侧热力图卡，表格在 `.md-scroll` 内滚动，避免列表把热力图卡拉高。
- 视口宽度不大于 `1100px` 时，双栏改为上下堆叠，并清除右侧卡片的同步高度。
- 视口宽度不大于 `1000px` 时，顶栏页签缩窄；不大于 `560px` 时，筛选中的宽字段和操作按钮不再强制跨列。

### 5.2 手机截图和热区

- 手机壳宽度为 `300px`，边框为 `8px`，圆角为 `32px`。
- 截图必须使用 `width: 100%` 和 `height: auto`，不应固定截图高度。
- 所有热区使用绝对定位，且其父容器必须是相对定位。
- 标签右侧容易溢出的区块使用 `hot-l`，让标签右对齐。
- 热区边框、选中态、hover 态分层设置，隐藏热色时不应把标签一并透明化。

### 5.3 表格约束

- 模块表、流量表和行为表使用固定列宽，避免排序或选中后因内容重排出现像素级跳动。
- 表头在内部滚动容器内吸顶，必须有不透明背景。
- 选中模块行用蓝色内阴影描边与浅蓝底色实现，不要用会影响行高或列宽的边框。
- 模块表主指标采用 UV、次指标采用 PV；进度条上层为品牌蓝、下层为灰蓝。

## 6. 性能与可维护性注意项

1. 方案 10 只遍历模块 DOM 并设置 CSS 变量，适合模块级热度；不要为了沿用旧代码而额外绘制隐藏 Canvas。
2. 图片、窗口和容器尺寸变化会触发热区计算。若新增频繁尺寸变动场景，应合并同一帧内的重复计算。
3. 旧连续 Canvas 方案会按设备像素比创建 `Float32Array` 和整屏图像数据，计算量显著高于方案 10。它适合视觉试验，不应在方案 10 中默认启用。
4. 当前旧方案的调参输入通过 `requestAnimationFrame` 限制为每帧最多重绘一次；若继续维护 Canvas 版本，应保留这一节流方式。
5. `name`、`data-mod`、表格行 `data-name` 和桑基图起始选项必须来自同一个模块配置源，避免重命名后联动失效。
6. 不要从显示文本反向解析真实业务指标。方案 10 为兼容现有结构从标签读取百分比；后续重构时宜让热区直接读取结构化指标值，并仅把标签作为展示层。
7. 真实数据接入前应明确曝光、点击、UV 去重、页面 UV 和日期边界的服务端口径；演示中的 `0.78`、重复点击系数、下游分布及策略数据不应沿用为生产规则。
8. 模块名悬浮浮层挂载到 `body` 并使用固定定位，是因为单元格设有 `overflow: hidden`。表格滚动时需主动关闭浮层，避免位置错位。

## 7. 历史与可选实现

### 7.1 `pageanalysis_heatmap_v2.html`：连续 Canvas 热场

该版本用 Canvas 为每个模块绘制有机连续热场。它根据模块区域和 UV 点击率计算归一化热度，使用多段蓝、青、绿、黄、橙、红色带，并把相邻模块的色相按权重平均，避免交界处累加出虚假的高热点。

其调参模型包含 `core`、`falloff`、`spread`、`cool`、`alpha`、`fade`、`tilt`、`knee`，支持本地存储、恢复默认和复制参数。适合研究连续热场的视觉效果，但不属于方案 10 的现行呈现。

### 7.2 `pageanalysis_heatmap_v2_品类列表窄版.html`：窄热区变体

该版本与连续 Canvas 版本基本一致，仅把“品类列表-组”从大面积区域改为右侧勾选框列：

| 项目 | 普通历史版 | 窄版 |
| --- | --- | --- |
| 左侧位置 | `17.5%` | `90.5%` |
| 宽度 | `81.5%` | `6%` |
| 顶部位置 | `38%` | `38%` |
| 高度 | `40.5%` | `40.5%` |

当分析对象是列表的勾选操作而不是整个品类列表时，可参考该坐标切分方式。方案 10 若采用该业务语义，也应只调整该模块的百分比坐标和标签对齐，不应改变其他模块的坐标规则。

### 7.3 `pageanalysis_heatmap_v2_旧热力图撒点版_20260918.html`：伪随机点云

该版本在每个模块内生成约 `50` 到 `90` 个确定性伪随机点，叠加为密度场并在每个模块内按峰值归一化。点云形态可以模拟常见热力图外观，但这些点不是点击坐标。因此仅适合比较视觉算法或在未来接入真实坐标埋点后改造；在现有模块级聚合数据条件下不应展示为真实用户点击位置。

### 7.4 `heatmap_demo.html`：多方案调试能力

调试页支持方案一至方案十的配色比较、遮罩颜色和透明度调整、模块描边、圆角、高亮数据、方案 10 色值与透明度编辑、椭圆内边距和模糊方式切换，以及配置复制。它的方案 10 与现行页面在核心概念上相同，但允许更多调试项：

- 分档阈值为 `10%`、`30%`、`55%`。
- 初始四个颜色为蓝、薄荷、浅黄、粉色。
- 可切换无模糊、图层模糊、背景模糊和叠加模糊。
- 可导出 `heatmap-config/v1` JSON 供调参复现。

这些调试控制项未在现行页面中开放。若要产品化某项能力，应先确定指标口径、默认值、权限和验收标准，再从调试页迁移；不能假定其已是现行页面功能。

## 9. 方案 10 验收清单

### 9.1 数据与映射

- [ ] 每个模块都具有唯一且一致的 `name`、`data-mod` 和表格 `data-name`。
- [ ] 热区标签、热区颜色和模块表中的点击率使用同一项 UV 指标。
- [ ] 切换到使用率时，标签、颜色和表头说明同步更新。
- [ ] 无曝光模块显示 `-`，不会参与曝光率的错误计算。
- [ ] 日期筛选后的日均值以包含首尾日期的天数计算。

### 9.2 视觉与布局

- [ ] 热色块是模块内的居中椭圆，未铺满整个区块。
- [ ] 小、中、大模块分别遵守当前内边距与模糊上限。
- [ ] 四档颜色与 `10%`、`30%`、`55%` 边界一致，不产生连续插值色。
- [ ] 模块描边、标签、选中轮廓没有被模糊。
- [ ] 标签不超出手机壳，密集区域的标签不会无故移动到不相关模块。
- [ ] 宽屏为双栏，宽度不大于 `1100px` 时改为上下堆叠。
- [ ] 右侧模块表在宽屏与热力图卡等高，并在内部滚动。

### 9.3 交互与稳定性

- [ ] 点击热区与点击表格行均能选中同一模块。
- [ ] 从热区点击不会改变桑基图起始模块；从表格点击会更新桑基图。
- [ ] 悬浮热区能高亮对应表格行。
- [ ] 点击空白区域可清除选中态，点击工具按钮或弹窗内部不会误清除。
- [ ] 热力图开关隐藏填色和边框，但不破坏已选中模块的可识别性。
- [ ] 模块名、曝光说明和父模块 ID 浮层在滚动、复制和离开时行为正确。
- [ ] 截图首次加载、窗口缩放和容器尺寸变化后，椭圆位置与尺寸均正确。
