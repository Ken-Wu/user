# 页面热力图（方案十）实现规则

## 1. 适用范围

- 页面：`pageanalysis_heatmap_v2_scheme10.html`。
- 原页面：`pageanalysis_heatmap_v2.html` 不修改。
- 热力图基于页面截图中的模块矩形区域渲染，不采集或推断模块内部真实点击坐标。

## 2. 默认展示

- 默认开启热力图与数据标签。
- 默认指标为“曝光点击率”。
- 工具栏支持“曝光点击率 ↔ 页面点击率”切换。
- 切换指标时，同步更新热区标签数值、热区颜色档位、模块数据列表中的选中联动状态。

## 3. 指标口径

| 指标 | 计算公式 | 用途 |
| --- | --- | --- |
| 曝光点击率 | 模块点击 UV / 模块曝光 UV | 默认热力指标、模块列表点击率 |
| 页面点击率（原“使用率”） | 模块日均点击 UV / 页面 UV | 切换热力指标、模块列表页面点击率 |

- 两个指标仅使用 UV，不计算或展示页面点击率的 PV 版本。
- 工具栏指标切换按钮不显示 `!`。
- 模块数据列表的“曝光点击率”“页面点击率”表头显示 `!`，hover/focus 展示口径说明。

## 4. 热区几何规则

- 每个模块对应一个绝对定位热区容器，热区为居中椭圆。
- 热区宽 = 模块宽 - 2 × 横向内边距；热区高 = 模块高 - 2 × 纵向内边距。

| 模块等级 | 模块面积 | 热区内边距 |
| --- | --- | --- |
| 小模块 | < 2,500px² | 8px |
| 普通模块 | ≥ 2,500px² 且 < 12,000px² | 16px |
| 大模块 | ≥ 12,000px² | 28px |

- 热区始终居中；空间不足时内边距安全收敛，保证热区最小正尺寸。
- 热区本体和模糊效果严格裁切在模块边界内。
- 不允许大模块额外扩散 5px 或任何越界扩散。

## 5. 色彩与透明度规则

- 热区采用离散四色分档，不进行颜色插值。

| 点击率 / 页面点击率区间 | 颜色 | 透明度 |
| --- | --- | --- |
| < 10% | #00B2FF | 32% |
| ≥ 10% 且 < 30% | #73FFDA | 32% |
| ≥ 30% 且 < 55% | #FFE580 | 32% |
| ≥ 55% | #FF80A0 | 32% |

- 热区内部为平坦色块，无透明度渐变；边缘柔化来自图层模糊。

| 元素 | 颜色 | 透明度 |
| --- | --- | --- |
| 地图遮罩 | #4294B5 | 6% |

## 6. 模糊规则

- 模糊类型为图层模糊，仅作用于热区填充层；默认模糊强度为 39px。

| 热区等级 | 实际热区面积 | 最大模糊 |
| --- | --- | --- |
| 小模块 | < 2,500px² | 8px |
| 普通模块 | ≥ 2,500px² 且 < 12,000px² | 16px |
| 大模块 | ≥ 12,000px² | 36px |

- 最终模糊值：`min(默认模糊强度, 当前等级最大模糊, 当前模块几何安全上限)`。
- 标签、描边、hover、选中框、点击区域不参与模糊。
- 模糊不可越过模块边界；不允许小模块溢出或大模块额外扩散。

## 7. 模块区域交互

- 点击热区时，高亮对应模块表行，表格自动滚动到该行，并可同步模块操作路径。
- 模块表行 hover 时，高亮对应热区。
- 关闭热力图时，隐藏热区颜色与模块描边，保留页面原图和既有页面功能。
- 热区标签默认显示，并按当前指标显示百分比。

## 8. 模块数据列表规则

- 字段顺序固定为：模块名 / 日均曝光 / 曝光率 / 日均点击 / 曝光点击率 / 页面点击率 / 操作。
- 日均曝光旁展示 `!`，说明曝光来源。

| 类型 | 说明 |
| --- | --- |
| 页面曝光 | 随页面曝光统一触发 |
| 自身曝光 | 模块进入可视区域后由自身触发 |
| 无曝光 | 模块未配置曝光事件，日均曝光与曝光率展示 `-` |
| 父模块曝光 | 继承父模块曝光，提示展示父模块 ID |

- 父模块曝光的日均曝光旁 `!` 说明入口可点击复制父模块 ID，复制后显示成功反馈。
- 所有 `!` 浮层挂载到 body，避免单元格裁切。

## 9. 自适应与性能

- 页面截图加载完成后计算热区尺寸；窗口尺寸变化时重新计算。
- 使用 ResizeObserver 监听热力图容器变化。
- 不使用 CSS transform 缩放热区，避免点击坐标与视觉位置偏移。
- 热区尺寸、模糊等级、内边距等级写入 data-* 属性，便于调试。

## 10. 验收标准

- [ ] 默认展示方案十热力图。
- [ ] 可切换曝光点击率/页面点击率。
- [ ] 切换同步标签与颜色。
- [ ] 工具栏无指标 `!`。
- [ ] 两个列表表头有 `!` 和说明。
- [ ] 无日均曝光展示 `-`。
- [ ] 父模块曝光可复制 ID。
- [ ] 三类模块内边距为 8px/16px/28px。
- [ ] 模糊为 8px/16px/36px 且不越界。
- [ ] 原页面表格联动、hover、选中、模块操作路径不受影响。
